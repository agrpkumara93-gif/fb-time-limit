Facebook Daily Time Limit

Limit: 15 minutes per calendar day.

How it works:
- Counts only when a Facebook tab is visible and focused.
- Time is cumulative across the whole day.
- At 15 minutes, the Facebook tab is closed.
- Facebook remains blocked until the next local calendar day.
- The counter is stored locally in Chrome/Edge.
- There is no reset button by design.

Install:
1. Unzip this folder.
2. Open chrome://extensions/ (or edge://extensions/).
3. Enable Developer mode.
4. Click Load unpacked.
5. Select the facebook-daily-limit folder.
6. Pin the extension if you want to see remaining time.
